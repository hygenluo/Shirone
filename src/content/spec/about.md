# 关于我

## 我在写什么

### AI / 大模型

LangGraph 的图执行机制与源码：State 状态模式、Router 路由、Tool Calling，以及接入大模型做问答流程的完整实践；此外也有 Transformer 与注意力机制的入门梳理。

### 算法与数据结构

LeetCode Hot 100 与笔试真题题解，覆盖哈希表、双指针、滑动窗口、前缀和、动态规划、单调队列等题型。习惯按「题目描述 → 思路 → 代码 → 复杂度」整理成可以随时回查的笔记。

### Python 工程

从语言核心语法（数据模型、流程控制、容器、函数、模块、面向对象）到 FastAPI、Streamlit 的实践，并用 Streamlit 搭配 DeepSeek 做过一个 AI 对话应用。

### 工具与协作

开源项目的参与流程、静态站点的构建与自动化部署。

## 关于本站

本站基于 **Astro** 构建，使用 [Shirone](https://github.com/LyraVoid/Shirone) 主题，界面遵循 Material 3 设计规范。全文搜索由 Pagefind 提供，中文字体在构建时按实际用字做子集裁剪。

站点采用**内容与模板分离**的双仓结构：文章、配置与媒体资源放在独立的私有内容仓，主题代码单独公开；推送内容后由托管平台以源码模式重新构建并发布。这样主题可以随时跟随上游更新，不必担心与个人内容产生冲突。
